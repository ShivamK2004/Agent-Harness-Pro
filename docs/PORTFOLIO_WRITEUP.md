## Recommended resume bullets

Use only after you have personally run the relevant features and can explain them:

- Built a modular Python agent harness supporting Gemini, Ollama, and offline Mock providers through a shared LLM adapter interface.
- Implemented a Planner–Researcher–Executor–Verifier workflow with per-stage traces, allowlisted tools, and advisory citation checks.
- Developed local knowledge retrieval with line-aware source references, a restricted AST-based calculator, and workspace-confined file operations.
- Created a benchmark runner with transparent keyword coverage, token-overlap, citation-marker, tool-use, and latency metrics; persisted run history in SQLite.
- Delivered a Next.js + React dashboard, FastAPI endpoints, and retained Streamlit fallback, offline pytest suite, and GitHub Actions workflow for automated tests.

## Before adding metrics to a resume

Run each provider over the same frozen benchmark dataset multiple times. Record model ID, prompt version, dataset version, run count, failures, latency distribution, and metric definitions. Report measured values exactly and label the small synthetic dataset as a demonstration dataset.
