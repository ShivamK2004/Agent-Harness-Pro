# Sample Security Principles

This file is illustrative project knowledge, not legal or compliance advice.

## Least privilege

A tool should receive only the permissions required for its specific task. This project exposes a small allowlist of tools and does not provide a shell or arbitrary code execution tool.

## Evidence and citations

When the local knowledge base returns evidence, responses should cite source identifiers such as [KB001]. If no evidence is available, the workflow should communicate uncertainty rather than fabricate a source.

## Human review

Outputs that could affect money, health, legal status, employment, account access, or safety require independent human verification. Model-based verification is advisory and must not be treated as authoritative.
